# TAI 仕様ダイジェスト

1つの短いサンプルを、4つの結合した臓器（状態変数）が勝手に代謝・変異させ続ける FM-1 用 CFW。niwa の `tai` ブランチ。
このファイルは「いまのコードがすること」と「次に足すものの設計」だけを書く。経緯は [decisions.md](decisions.md)。

- **いまあるもの（縦切り1）**：状態モデル `firmware/src/tai/organs.h`（純C・整数）、ホストシミュレーション `tests/tai/sim.c`（CSV）、
  生体モニター画面とノブ・鍵盤の介入 `firmware/src/tai.c`、ブラウザ版（GitHub Pages、`tai` ブランチから）。
- **まだないもの**：DSP（音はまだ体に繋がっていない。鍵盤の下に短いサイン音が鳴るだけ）、上段アンプル、サンプルの注入。
- 確かめ方の区別：「ホストで測った」＝ `tests/tai/sim.c` / `emu_test.mjs`。実機では何も確かめていない。

## 1. 内部状態変数（バイタル）

すべて Q15（0..32767 = 0..1）。例外は `hr`（bpm の Q8）と位相（2^32 で1周）。1ステップ = 5 ms（200 Hz）、メインループで回す。
耳で決める数値は `organs.h` 冒頭の `ORG_*` と各式の係数にだけ置く。

| 臓器 | 変数 | 意味 | 一次作用（ノブ） | 二次波及（隣へ） |
|---|---|---|---|---|
| 1 心（循環） | `hr` `phase` `beats` | 心拍数・拍の位相・拍のカウンタ（DSP のトリガー） | K1 PRESSURE：40〜180 bpm | — |
| | `co` | 心拍出量 = 心拍 × 1回拍出（体液が溜まると減る） | | **co → 肺の換気を加速** |
| | `attack` | 1拍の硬さ（K1 × 拍出） | K1：アタック | |
| | `arrest_ms` `refract_ms` `escapes` | 停止の長さ・補充調律後の不応・安全弁の発火回数 | | |
| 2 肺（呼吸） | `vent` `rphase` | 換気 = グレインの走査速度・呼吸の位相（6〜36回/分） | K2 VENT：粒度・空気 | |
| | `co2` | 血中CO2。産生（co・熱）− 排出（vent × co2）。0.5 が設定点 | | |
| | `alk` | アルカローシス = 設定点からの CO2 の不足 × 3 | | **alk → 筋の Q を過敏に** |
| 3 筋（電解質） | `q` | レゾネーターの鋭さ | K3 TENSION：倍音の純度 | |
| | `osc` | 自励発振：`q > ORG_Q_OSC (0.62)` の間だけ育ち、下で減衰 | | |
| | `heat` | 熱 = osc と張力から入り、代謝で抜ける | | **heat → 体液が漏れて空間が膨らむ** |
| 4 体液（免疫・循環） | `vol` | 空間の体液 = リバーブの満ち・減衰 | K4 STASIS：深さ・濁り | |
| | `brake` | 迷走神経ブレーキ：`vol` 0.62〜0.92 で滑らかに 0→1 | | **brake → 心拍を下げ、止める** |
| 体質（エンコーダー） | `compliance` | 硬い（速く追従）〜柔らかい（遅く滲む） | SELECT | 心拍の追従時間 0.25〜1.2 s |
| | `metabolism` | すべての排出（熱・体液）の速さ ×0.3〜1 | PRESETS | |
| | `electrolyte` | 共鳴の音階の引力（**まだ未接続**） | ALGORITHM | |
| 潮 | `drift[4]` `lean[4]` | 各臓器の目標が約12秒ごとに ±0.18 の範囲で傾き直す | — | 手を離しても止まらない |
| 手 | `occlude` `reperf` `cold` | 阻血中・再灌流の反動・冷却ショック（減衰する） | 鍵盤 | |

### 結合の形

```
  K1 ─▶ [心 hr,co] ──co──▶ [肺 vent,co2] ──alk──▶ [筋 q,osc,heat] ──heat──▶ [体液 vol] ─┐
           ▲                                                                            │
           └──────────────────────── brake（符号が反転：抑制）◀───────────────────────────┘
```

- 4つは全部リーキー積分器（`q15_leak`：毎ステップ目標へ一定割合だけ寄る）。輪の中に符号の反転が1つ（brake）だけあるので、
  系は平衡を探して行き過ぎる：体液が溜まる → 徐脈・停止 → 拍出が落ちて換気・熱が下がる → 体液が抜ける → 再鼓動 → また溜まる。
- しきい値は全部 `q15_smooth`（3t²−2t³）で曲げる。折れ線にしないので、破綻は「段」ではなく「傾き」で来る。
- 腎の排出は拍出に比例：止まっている間は抜けにくい。だから停止は放っておくと長引く（下の安全弁がそれを切る）。
- 潮（drift）が無いと、ノブを止めた体は数十秒で固定点に落ちた（ホストで確認）。潮が「言うことを聞かない」の最低限。

### 安全弁（心停止は必ず自動で戻る）

- 停止（`hr < 22 bpm`）が `ORG_ESCAPE_MS`（6 s）続いたら**補充調律**：brake を 0 にして `ORG_REFRACT_MS`（3 s）抑え、体液を半分抜き、
  40 bpm で拍を1つ打つ。どのノブ位置でも、停止が 6 s を超えないことを `tests/tai/sim.c` が全シナリオで検査する。
- 鍵盤（低域 PACE）でもっと早く戻せる：1打ごとに brake ×0.6、体液 −3%、拍を1つ強制。

| rest（全部 0.5、10分） | 84〜134 | 0.38〜0.66 | 0 | 0 % |
| K1 だけ最大 | 155〜182 | 0.33〜0.47 | 0 | 0 % |

## 2. DSP シグナルフロー（設計。未実装）

1つの共通サンプルバッファを4トラックが別々に読む。体（`org_body`）はメインループが書き、音声割り込みは5 ms ごとのスナップショットを読むだけ
（1変数1書き手、`volatile`：niwa `docs/API.md`）。

```
             ┌────────────────── 代謝バッファ（出力を食べる：短いリング 0.5〜1 s）◀──────────────────┐
             ▼                                                                                   │
 標本 ──┬─▶ T1 PULSE   beats で頭出し。attack＝エンベロープの立ち上がりと歪み量 ───────┐              │
 (flash)├─▶ T2 GRAIN   2〜4粒。走査速度＝vent、粒長＝K2、粒の密度は rphase で吸気/呼気 ─┤              │
        │                                                                          ▼              │
        │                     T3 RESONATOR  モーダル 4本（2極 BP）。Q＝q、発振＝osc で帰還>1＋ソフトリミット
        │                                   ピッチ＝ELECTROLYTE の音階へ引かれる ──────────────┐   │
        │                                                                               ▼   │
        └──────────────────────────────────────────────────────────▶ T4 SPACE  ディレイ1本＋全域通過4段＋減衰コム
                                                                     減衰＝vol（→ほぼ無限、リミッタつき）、濁り＝K4 の LP ──▶ 出力
```

- **オートファジー**：最終出力を代謝バッファに書き戻し、T2 の粒は原音と代謝バッファの両方から読む。混ぜる比と忘れる速さ＝METABOLISM。
  FREEZE（アンプル）＝書き込みと体の時間を止める（S-4 の Buffer Lock）。
- **送りの量はつまみにしない**：T3・T4 への送りは体（osc、vol）が決める（niwa PHILOSOPHY 2「人に決めさせない」）。
- **出自**：T2 は maku の `GRAIN`、T3 は maku の `PHYS`（DaisySP / Elements 由来）、T4 は maku の空間系から移植する予定。移植時に出自を表記する。
- **予算（未測定）**：AC791N の RAM 配置と DSP の余力は実機・予算テストで測るまで断定しない。3 s のモノラル 16 bit 44.1 kHz は 265 KB で、
  RAM に置けるかは未確認（置けなければ flash の XIP から読むか、22.05 kHz に落とす）。移植の段ごとに `emu_test` の cost 行とホストの計測で余力を見る。

足す順（docs/decisions.md）：T1 パルス → T3 レゾネーター → T4 空間 → ノブ4本の音への接続。T2 と鍵盤3帯域・アンプル・エンコーダーの音への効きは音が気に入ってから。

## 3. 生体モニター（実装済み、`tai.c`）

手術室のベッドサイドモニターの配色：黒地、信号ごとに1色、トレースを左・その数値を右に同じ色で大きく、警報は赤。
（固定 RGB。UI.md 5.1 のトラック色の例外に、黒とグレーも含めた。decisions 参照）

```
 x 0                   152 153        239
   ┌─────────────────────┬────────────┐ y 0
   │ 緑  ECG II          │ ECG II <FLUID│  数値 HR（停止中は赤 "---" と ASYSTOLE が点滅）
   ├─────────────────────┼────────────┤ 50
   │ 黄  RESP（カプノ）   │ RESP  KNOB  │  数値 RR
   ├─────────────────────┼────────────┤ 100
   │ 水色 EMG（筋電）     │ EMG  <LUNG  │  数値 Q。発振中は棘波が群発
   ├─────────────────────┼────────────┤ 150
   │ 青  CVP（液面）      │ CVP <MUSCLE │  数値 CVP。体液の高さまで塗りつぶし
   ├─────────────────────┴────────────┤ 200
   │ COMPL  METAB  ELYTE  SWEEP        │
   └──────────────────────────────────┘ 240
```

### 値を動かしているのが「ノブ」か「相互作用」かの見分け

各レーンの数値の下のバーと、右上のタグで示す。モデル側は `org_body.base[4]`（ノブだけならこの値）、`push[4]`（他からの押し、符号つき）、`src[4]`（最大の押し手）を出す。

| 表示 | 意味 |
|---|---|
| バーの実線（トレースと同じ色） | ノブだけで説明できる分 |
| バーの琥珀色 | 他の臓器・手・潮に押し上げられている分 |
| 実線の先の中抜きの枠 | ノブなら届くはずが、他に押し下げられて届いていない分 |
| タグ `KNOB`（白） | そのノブを回して 2 秒間 |
| タグ `<HEART` `<LUNG` `<MUSCLE` `<FLUID`（琥珀） | 他の押しが大きい（0.07 以上）とき、その最大の押し手。`<HAND` は鍵盤、`<TIDE` は潮 |

つまみを回した直後はバーの実線が伸びてタグが KNOB、手を離して数値だけ動いているときは琥珀と `<…` が出る。
結合の向きは輪の通り：HEART ← FLUID（ブレーキ）、LUNG ← HEART（拍出）、MUSCLE ← LUNG（アルカローシス）、FLUID ← MUSCLE（熱）。
CVP のバーは、体液の水位を「ノブの注入」と「熱の漏出・潮」の流入の比で分けている。

### 描画

- **掃引式**：1列ずつ左から右へ書き、6列先を消す。画面全体は塗り直さない（niwa LESSONS 1）。
- 1列＝縦線4本＋消去1本の `lcd_fill`。列の間に体は数ステップ進むので、各トレースはその間の最小〜最大を縦線にする。
- 数値とバーは 200 ms に1回まで、変わったときだけ（87×50 のキャンバス4枚）。
- OCT− / OCT+：掃引速度 12.5 / 25 / 50（1画面 約9 / 4.5 / 2.3 s）。

## 4. 操作（いま）

| 操作 | 効き |
|---|---|
| KNOB 1〜4 | PRESSURE / VENT / TENSION / STASIS（起動時 64、保存しない） |
| SELECT / PRESETS / ALGORITHM | COMPLIANCE / METABOLISM / ELECTROLYTE（保存する） |
| OCT− / OCT+ | 掃引速度（保存する） |
| 鍵盤 下 9 鍵 | PACE：拍を1つ強制、ブレーキを緩める |
| 鍵盤 中 9 鍵 | OCCLUDE：押している間、臓器間の結合を 0.1 倍に。離すと再灌流の反動（心拍・換気・Q・熱が跳ねる） |
| 鍵盤 上 9 鍵 | COOL：発振を消し、換気と Q を一気に落とす |
| USB-MIDI ノート | 同じ高さの鍵盤として効く（範囲外は端の帯域） |

FM-1 の鍵盤は 27 鍵（F3〜G5）なので、構想の「25鍵の3帯域」は 9 鍵ずつにした。
