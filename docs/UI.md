# niwa の UI システム

maku の画面・LED の作法（maku `docs/UI_RULES.md`）を、MAKU 固有の中身（PULSE / FLOOR などの名前、動詞の割り当て）を外して、
どの CFW にも使える形にしたもの。t8lab はこの作法に乗って作られ、「見た目を変えない」ことを確かめている（t8lab decisions 2026-10-11）。

- 凡例：**[必須]** 変えると様式が崩れるか、過去に不具合を出したもの。**[既定]** 理由があれば変えてよい値。
- 破るときは、その CFW の `docs/decisions.md` に理由を1行残す。
- niwa の実装：画面の道具は `firmware/src/gfx.c`、2×2 の骨組みは `firmware/src/quad.h`、使い方の例は `niwa.c`（[API.md](API.md)「Screen」）。起動時のフェードインと消去の凹みは `soft.h`、電池の通知は `battery.h`。
- 実装の出どころは maku `73d9d1a`（`firmware/src/ui_maku.c`、`gfx.c`、`tools/gen_ui_palettes.py`、`tools/gen_aa_font.py`）。
  niwa への取り込みの範囲は [HARVEST.md](HARVEST.md)。

---

## 1. 原則

1. **[必須] 画面はつまみの物理配置の地図。** 240×240 を 2×2 に割り、本体左の 2×2 のつまみ（MASTER / SELECT / PRESETS / ALGORITHM）と同じ位置に、そのつまみが動かすものを出す。画面を見なくても「右上を回せば右上が変わる」。
2. **[必須] ページ送り・画面遷移・メニューを作らない。** 1つのモードのパラメータは3つまで（3区画に1つずつ）。収まらなければ機能を削るか、別のボタン（動詞）に分ける。設定メニューだけは例外（普段は見えない場所）。
3. **[必須] どのモードも同じ様式。** つまみの役割が変わっても、区画のレイアウト・フォント・位置は同じで、中身（名前・値・ゲージ）だけが入れ替わる。モード専用の画面を作らない。
4. **[必須] 押している間だけ変わる。** 離せば元の画面。状態を覚えるトグル・ラッチは例外で、見出しに ON / OFF を出し、LED でも見せる。
5. **[必須] 左上は常に「いま」を出す。** 何を押していても、左上（MASTER の場所）は入れ替えない。何を出すかは CFW ごと（maku：波形・フォーカス・調・BPM・4つの音量）。
6. **[既定] 値は 0〜127 の整数。** 右に回すほど盛り上がる向き。単位や小数は出さない（テンポは例外にしてよい）。

## 2. 4つの音量と1つのフォーカス（maku・t8lab 共通の骨格）

- **[既定] KNOB 1〜4 は4トラックの音量。回したトラックにフォーカスが移る。** SELECT / PRESETS / ALGORITHM はフォーカス中のトラックの3パラメータ。
- **[必須] ボリュームノブは常に音量。** 層（EDIT・GLO など）の裏でも音量のまま。「EDIT + ボリュームノブで音色」は混乱したので外した（t8lab 2026-10-12）。
- 実装は `firmware/src/tracks.h`（音量4つ・フォーカス・沈める棒グラフ）。音は持たない。`niwa.c` が見本。
- トラックが4つでない CFW は、この節ごと変えてよい（decisions.md に1行）。

## 3. レイアウト（ピクセル）

```
 x: 0        119 121       240
   ┌──────────┬┬──────────┐ y: 0
   │ 左上 いま ││ 右上      │
   │ (MASTER)  ││ SELECT    │
   ├──────────┼┼──────────┤ 119..120 の2pxが区切り線
   │ 左下      ││ 右下      │
   │ PRESETS   ││ ALGORITHM │
   └──────────┴┴──────────┘ 240
```

- **[必須] 区画は 119×119、区切り線は 2px（x/y = 119〜120、`T_LINE`）。** 区画の原点は (0,0)・(121,0)・(0,121)・(121,121)。
- **[必須] パラメータ区画の中は全区画・全モード共通：**

| 要素 | 位置 (x, y) | フォント | 色 |
| --- | --- | --- | --- |
| つまみの名前（SELECT / PRESETS / ALGORITHM） | (8, 6) | S | `T_DIM` |
| モード名（動詞・層の間、SELECT 区画の右上だけ） | 右端から 6px、y 6 | S | `T_ACCENT`（OFF なら `T_MID`） |
| パラメータ名 | (8, 24) | M | `T_MID` |
| 値 | y 48、区画の幅でインクの中心に揃える | L | トラック色 / モード中は `T_ACCENT` |
| ゲージ | (8, 92)、幅 119−16、高さ 4 | — | 下地 `T_LINE`、量はトラック色 / `T_ACCENT` |
| 追加の帯（ステップ列など） | y 104〜 | — | 5.2 |

- **[必須] 余白は左右 6〜8px。** 左寄せは x 8（左上は x 6）、右寄せは右端から 6px。
- **[必須] 中央揃えはインク（字の黒い部分）で揃える**（`ink_in` / `cv_text_in`）。送り幅で揃えると最大 1.5px ずれる。割り切れない 1px は左・上へ（`HALF_UP`）。
- **[既定] ゲージは 0〜127 を幅に比例。** 0〜127 でない値は写してから描く。

## 4. 文字

- **[必須] フォントは Inter Tight の3つだけ**（`gen_aa_font.py --preset inter-tight`、4bit アンチエイリアス）：S 12px/400（つまみ名・単位・メッセージ）、M 15px/500（パラメータ名・トラック名）、L 28px/600（大きな値だけ）。
- **[必須] L は `" #+-./0-9A-Y"` しか持たない**（容量）。L に出すのは数字・大文字の短い語・`#`。文字が要るなら `L_CHARS` に足してサイズを確かめる。
- **[必須] 表示名は大文字の英語の短い語、7文字まで**（バッファ 8 バイト）。ボタンに印字のある動詞は印字と同じ名前。
- **[必須] 小さいフォントに逃げない。** 入らなければ末尾を省略記号に（`text_fit`）。長くなりうるメッセージだけ最初から S。
- **[必須] 文字は `cv_text` を通して置く**（生成したテーブルのサブピクセル位相とカーニング）。`text_spacing_test.py` が 0.25px（L は 0.5px）のずれで落ちる。
- **[既定] 上ほど小さく暗く、値がいちばん大きく明るい**：ラベル（S、DIM）→ 名前（M、MID）→ 値（L、色）。

## 5. 色

### 5.1 トークンだけで描く

- **[必須] 描画コードに RGB を書かない。** 色は `T_*` トークンだけ。トークンは `gen_ui_palettes.py` の5色（BG / SURF / TEXT / THEME / ACCENT）から `palette_set()` が決まった比率で作る：

| トークン | 作り方 | 使いどころ |
| --- | --- | --- |
| `T_BG` | BG | 背景 |
| `T_TEXT` | TEXT | 主な文字 |
| `T_MID` | BG→TEXT 70 % | ラベル、パラメータ名 |
| `T_DIM` | BG→TEXT 42 % | つまみ名、無効・空 |
| `T_LINE` | BG→TEXT 18 % | 区切り線、ゲージの下地、空のステップ |
| `T_RAISE` | SURF→TEXT 12 % | 波形の中心線、くぼみ |
| `T_THEME` | THEME | 値・曲線 |
| `T_ACCENT` | ACCENT | **いま操作中の1つだけ** |
| `T_REC` | 固定の赤（GREY・MONO では ACCENT） | 録音・いいね |

- **[必須] 例外はトラック色だけ。** トラックごとに固定の色を持たせ、そのトラックが出るところは全部その色。MONO では `T_THEME` に戻す（形と位置で区別）。GREY では文字だけ `T_THEME`、バー・ゲージ・波形は色のまま（`mk_ink` と `mk_col`）。
- **[必須] トラック色の混色は RGB チャネルごと**（`mk_mix`）。パレット側の `ux_mix` は GREY で灰色にしてしまう。
- **[必須] パレットは追記だけ**（保存された設定が番号で指す）。ツールは全組み合わせの WCAG コントラストを検査してビルドを落とす。検査を外さない。GREY は R=G=B、MONO は混色しない。

### 5.2 状態の色

- **[必須] `T_ACCENT` は「いま触っているもの1つ」。** 同時に2か所を ACCENT にしない。
- **[必須] トラック色 = 普段の値、`T_ACCENT` = 押している間だけの値。** 色の違いで「一時的なモードにいる」と分かる。
- **[必須] フォーカスしていないものは消さずに沈める**（トラック色を BG へ 55 %、番号は `T_MID`、フォーカス中だけ下に 2px の線）。
- **[既定] ステップ列：** 打つ = トラック色 8px、確率・ゴースト = `T_MID`（高さで確率）、空 = `T_LINE`、再生位置 = `T_ACCENT` 12px。

## 6. 一時的な表示とタイミング

- **[既定] 回した直後のハイライト 40 フレーム、メッセージ 60 フレーム**（約60fps）。メッセージは左上の名前の場所に S / `T_ACCENT`。続きは待ち行列に積み、2つを同時に出さない。
- **[必須] ハイライトは、それを起こした操作子のものだけ。** 別の操作子の番号同士を比べない（maku 3eafae6、[LESSONS.md](LESSONS.md)）。
- **[必須] 新しい状態・メッセージで画面の構成を変えない。** 文字が入れ替わるだけ。

## 7. 描画の実装

- **[必須] 区画ごとにオフスクリーンで描いて一度に転送**（`cv_begin` → 描く → `cv_blit`）。LCD に直接部分描きしない。
- **[必須] 動くもの（波形）だけ毎フレーム、ほかは変わったときだけ。** 区画に出る値は全部「署名」に混ぜ、署名が変わったときだけ描き直す。**新しい表示を足したら、その値を署名に足す。**
- **[必須] つまみ・ボタンの操作で全画面の描き直し（`ui.force`）を立てない。** 全画面を黒で塗ってから描くので、回すたびに点滅する（maku fa19873・4ffebe6）。全画面は電源オン・画面の復帰・パレット変更のときだけ。
- **[必須] 描画はメインループで。** ISR から画面に触らない。重い処理（抽選・保存）も ISR に入れない。
- **[既定] 波形はゼロクロスでトリガー、ピークで正規化**（最小ピーク 1500）、2px の線、中心線 `T_RAISE`。

## 8. LED

- **[必須] LED の絵はオフラインで組んでから一度に出す。** 点灯→減光の間に消灯のフレームを挟まない。
- **[必須] 意味を固定する：** 点灯 = 状態が ON、呼吸（ゆっくり明滅）= その層・モードを開いている間、減光（グロー）= 押せるもの・スケール内の鍵。
- **[必須] LED のモード設定（OFF / DIM / INV など）を全部尊重する。** 新しい LED は 点灯 / グロー / 呼吸 のどれかに置き、合成をそのまま通す。
- **[必須] 電源オンのスイープ中は LED に触らない。**

## 9. ハード前提：安価な電池駆動・小さな内蔵スピーカー

コードの目印 `MANNER:<名前>` で実装を探す（`grep -rn "MANNER:" firmware`）。目印は動作を変えても消さない。新しく足すときは同じ形で目印を付け、表に1行足す。

| 目印 | 守ること |
| --- | --- |
| `MANNER:fade-in` | **[必須]** 電源オンの最初の約 0.8 秒は無音からふくらむ（二乗カーブ）。MASTER が上がっていても小スピーカーで叫ばない |
| `MANNER:erase-dip` | **[必須]** フラッシュ消去（約 40 ms、割り込み禁止で音が止まる）は、約 10 ms で下げ → DAC が無音を鳴らしきるのを待つ → 消去 → 約 25 ms で戻す。保存は必ずこの関数を通す |
| `MANNER:rec-preerase` | **[必須]** 押した瞬間に消去しない。書く側は人が聞いていない時（電源オン前、世界の切り替わり）に先に消し、消去済みの区画への保存は消去を省く |
| `MANNER:battery` | **[必須]** 電池はふだん画面に出さない（左上は「いま」）。電池駆動で残り1本以下が5秒続いたらメッセージで約2秒、1本減ったら即、以後2分ごと。USB ホスト接続中は出さない |
| `MANNER:leds-auto` | **[既定]** LED は AUTO：電池なら DIM LO、USB ホストがあれば DIM HI。充電器だけは電池扱い |

## 10. テストで守る

- **[必須] 見た目の不具合は、直すときにテストを1つ足す**（例：「つまみを回しても全画面が塗られない」）。
- **[必須] テストから画面のスクリーンショット（PPM / PNG）を出せるようにする。** レイアウトを変えたら見比べる。niwa のホストモード（`tests/run_host.sh`）はすでに PNG を出す。
- **[必須] パレットのコントラスト検査と文字間の検査を外さない。**
- **[既定] エミュレーターは同じ C の描画をそのまま使う。** エミュレーター専用の描画を作らない（t8lab で JS の別画面を作って作り直した、[LESSONS.md](LESSONS.md)）。

## 11. CFW ごとに変えるもの・変えないもの

| 変えてよい（CFW の中身） | 変えない（niwa の UI システム） |
| --- | --- |
| トラックの数・名前・トラック色 | 2×2 の区画とつまみの対応、119px + 2px の格子 |
| 各つまみ・動詞のパラメータ名と意味 | 区画内のラベル→名前→値→ゲージの配置と色の役割 |
| 左上に出す「いま」の中身 | 左上は入れ替えない |
| パレットの追加 | トークンだけで描く、追記のみ、コントラスト検査 |
| タイミングの値（40 / 60 フレーム） | ACCENT は1つ、ハイライトは起こした操作子だけ |
| L フォントの文字集合（足すだけ） | フォント3つ、小さいフォントに逃げない、インクで中央揃え |
| — | 署名で描き直す、操作で全画面を描き直さない、オフスクリーンで描く |

### 新しい画面のチェックリスト

- [ ] 1モードのパラメータは3つ以下か。ページ送りが要らないか
- [ ] 押している間だけ変わり、離せば戻るか。左上は残っているか
- [ ] 色は `T_*` とトラック色だけか。`T_ACCENT` は1か所だけか
- [ ] 値は L で出せる文字だけか。名前は大文字で7文字以内か
- [ ] 新しく出した値を署名に足したか
- [ ] 操作のハンドラで全画面の描き直しを立てていないか
- [ ] MONO・GREY・明るい背景のパレットでも読めるか
- [ ] スクリーンショットで点滅・ずれがないか見たか

## 12. まだ実機で確かめていないこと（maku から引き継ぎ）

- 暗い LCD で `T_DIM`（42 %）と `T_LINE`（18 %）が読めるか（コントラスト検査は計算上のもの）。
- 波形を毎フレーム描くコスト、画面あり / なしの電池の持ち。
- 起動のフェードイン 0.8 秒と、消去の凹み（約 10 + 40 + 25 ms）の聞こえ方。
- 小スピーカーで低域がどれだけ出るか。音色の評価に「内蔵スピーカーでの聞こえ」を足す。
